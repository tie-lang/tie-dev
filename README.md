# tie-dev

**tie 语言 AI 开发技能** / *AI development skill for the tie language*

tie-dev 是 tie 生态的 AI 开发技能包（SKILL.md + 支持文件）：面向 AI 编程助手，
承载 tie 语言开发任务的领域知识、约定与工作流（编码规范、p.x.x.x 编号、
文档/测试纪律等）。使用方将本技能目录装载进 AI 工具（如 Trae/Claude 类 IDE
技能系统）后，AI 助手即可按 tie 生态规范参与开发。

*EN: tie-dev is the AI-development skill pack for the tie ecosystem
(SKILL.md + support files): domain knowledge, conventions and workflows for
AI coding assistants working on tie-language projects (coding standards,
p.x.x.x numbering, docs/test discipline). Load this skill directory into an AI
tool (e.g. a Trae/Claude-style IDE skill system) to have the assistant develop
per tie-ecosystem conventions.*

## 使用 / Usage

- 将本仓 `SKILL.md`（连同支持文件）放入 AI 工具的 skills 目录并启用
- 与 [tie-lang/tie-main](https://github.com/tie-lang/tie-main)（聚合/发行仓）
  及其他组件仓配合使用

## 内容 / Contents

- `SKILL.md`：技能主文档（tie 开发上下文 + 规则 + 工作流）
